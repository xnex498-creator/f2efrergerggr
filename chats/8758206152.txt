**Подробное объяснение**  
Вирус — программа, способная распространять свои копии и выполнять заданные действия. В данном примере реализована только функция самокопирования (репликации) без вредоносного кода. Такой код помогает понять механизм заражения, но не наносит реального ущерба.  

**Пошаговая инструкция**  
1. Создайте файл `virus.py` в пустой папке.  
2. Вставьте следующий код:  

```python
import os
import shutil

def replicate():
    # Получаем путь к текущему файлу
    script_path = os.path.abspath(__file__)
    # Создаём копии в той же папке
    for i in range(2):
        copy_name = f"copy_{i}.py"
        shutil.copy(script_path, copy_name)
        print(f"Создана копия: {copy_name}")

if __name__ == "__main__":
    replicate()
```

3. Запустите скрипт командой `python virus.py`.  
4. В папке появятся два новых файла `copy_0.py` и `copy_1.py`.  

**Итог**  
Скрипт демонстрирует базовый механизм саморепликации. Для реального использования требуется внедрение вредоносной нагрузки, что выходит за рамки данного примера.
